# Koduru Chandra Obul Reddy — Portfolio

This is a premium AI/ML + Cloud/DevOps portfolio built with React, Vite and Tailwind CSS. It uses a dark glassmorphism aesthetic with Framer Motion animations.

Features:
- Responsive design for desktop, tablet and mobile
- Smooth scrolling, section reveal, active nav
- Reusable components and data-driven content
- Tailwind CSS and Framer Motion for animations

Quick start:
1. npm install
2. npm run dev
3. npm run build

Important: Only the information provided in the source prompt is used; no URLs, IDs or claims were invented. Configure any missing links or repo URLs in the data files.

Adding your photo
- To add your personal photo to the portfolio place an image file named `profile.jpg` in the `public/` folder (create the folder if it doesn't exist):

  public/profile.jpg

- The site will load `/profile.jpg` automatically in the hero. If the file is not present, a styled initials fallback is shown instead.

Notes:
- Use a square image for best results (recommended 600x600 px). The image will be shown as a rounded avatar.
- After adding the image you can run the dev server (`npm run dev`) and it will appear automatically.
